# Курсовая работа по Python 3

Проект сделан только на стандартной библиотеке Python.

## Структура

- `main.py` — точка входа для запуска командой `python main.py`.
- `coursework/main.py` — главное меню и подменю.
- `coursework/modules/` — модули с функциями по темам.
- `coursework/data/` — пример текстового файла и матрицы.

## Запуск

```bash
python main.py
```
